# BSOD 设计器

一个基于浏览器的可视化设计器，用来编排蓝屏上的文字与二维码布局，
并自动生成带**等比例缩放修正**的 C 渲染代码。

## 运行

```bash
# 方式一：直接双击/浏览器打开
xdg-open designer.html

# 方式二：本地服务器（推荐，某些浏览器限制 file:// 协议）
python3 -m http.server 8917 --bind 127.0.0.1
# 然后浏览器访问 http://127.0.0.1:8917/designer.html
```

## 界面

- **左-上（功能区）**：设置画布宽高（像素）、预设分辨率、添加「文字/二维码」元素、编辑选中元素属性。
- **左-下（代码区）**：实时生成的 C 代码，可一键复制。
- **右（设计区）**：画布预览。点击元素选中、拖拽移动；红色虚线框为选中范围。

## 元素（单位均为像素）

| 类型 | 属性 |
|------|------|
| 文字 | 内容、X、Y、字号、颜色 |
| 二维码 | 内容、X、Y、总尺寸、留白（模块数）、内容色、背景色 |

> 设计区里的二维码是**占位预览**（三个定位角 + 内容相关的伪随机图案），
> 真正可扫描的二维码由生成的 C 代码在运行时编码。

## 生成的代码与缩放修正

生成的代码块计算比例因子，把画布**等比例缩放并完整居中**放进实际屏幕：

```c
const float SCALE = (SCREEN_W / 1920.0f) < (SCREEN_H / 1080.0f)
                    ? (SCREEN_W / 1920.0f) : (SCREEN_H / 1080.0f);
const int OX = (int)((SCREEN_W - 1920.0f * SCALE) / 2.0f);
const int OY = (int)((SCREEN_H - 1080.0f * SCALE) / 2.0f);
```

所有元素坐标/字号/尺寸都乘以 `SCALE` 并加上 `OX/OY` 偏移，
保证无论实际屏幕多大，画布内容都能完整显示。

## 使用步骤

1. 打开设计器，设置画布尺寸（建议与目标屏幕同分辨率，缩放比为 1）。
2. 添加文字/二维码元素，拖拽定位，或直接在属性面板输入像素坐标。
3. 点击「复制代码」，得到元素布局块（含 `SCALE/OX/OY` 缩放换算）。
4. 把布局块粘贴到 `src/bsod.c` 的 `bsod_render_modern()` 函数内（现代渲染路径）。
   注意：该函数内部已经通过 `map_design()` 算好 `SCALE/OX/OY` 并持有
   `font_ctx *fc` 与 `render_ctx *r`，因此：
   - **删除**生成块中自行声明的 `SCALE/OX/OY`（避免重复定义）；
   - 把 `font_draw_text(&rctx, ...)` 调整为
     `font_draw_text(fc, r, ...)`、`qr_draw(&rctx, ...)` 调整为 `qr_draw(r, ...)`；
   - 文字绘制需在 `font_load()` 成功后进行。

> 更省事的替代方案：布局固定的文字也可以用新增的 `--string 'text|x|y|size|color'`
> 或配置文件 `[strings]` 段直接叠加，无需改代码（详见仓库根目录 `bsod.conf.example`）。
